# 3D Floor Plan Reconstruction - Web Demo

Convert 2D floor plan images to 3D OBJ models instantly using deep learning and computational geometry.

## Overview

This web application provides a user-friendly interface for the complete 3D floor plan reconstruction pipeline:

1. **FPN Inference** - 13-class semantic segmentation of floor plan
2. **Boundary Extraction** - Extract room polygons and walls from segmentation
3. **Wall Extrusion** - Convert 2D room boundaries to 3D geometry
4. **OBJ Export** - Export 3D models in OBJ + MTL format

## Features

✅ **Drag & Drop Upload** - Easy file upload interface  
✅ **Real-time Processing** - Fast inference with GPU support  
✅ **3D Model Download** - OBJ + MTL files ready for viewers  
✅ **Responsive Design** - Works on desktop and mobile  
✅ **REST API** - Programmatic access to pipeline  

## Installation

### Prerequisites

- Python 3.8+
- conda or venv
- PyTorch (with CUDA for GPU, or CPU)

### Setup

1. **Clone and navigate to web_demo directory:**
```bash
cd web_demo
```

2. **Create virtual environment:**
```bash
python -m venv venv
source venv/bin/activate  # On Windows: venv\Scripts\activate
```

3. **Install dependencies:**
```bash
pip install -r requirements.txt
```

4. **Verify FPN model location:**
```bash

```

## API Endpoints

### POST /api/upload
Upload floor plan image

**Response:**
```json
{
    "status": "success",
    "task_id": "20240101_120000_floorplan",
    "message": "File uploaded..."
}
```

### POST /api/process/<task_id>
Process uploaded image

**Response:**
```json
{
    "status": "success",
    "task_id": "20240101_120000_floorplan",
    "obj_file": "floorplan.obj",
    "mtl_file": "floorplan.mtl",
    "metadata": {
        "steps": {
            "fpn_inference": {...},
            "boundary_extraction": {...},
            "wall_extrusion": {...},
            "obj_export": {...}
        }
    }
}
```

### GET /api/download/<task_id>/obj
Download OBJ file

### GET /api/download/<task_id>/mtl
Download MTL file

### GET /api/preview/<task_id>
Get 3D model preview data

**Response:**
```json
{
    "status": "success",
    "vertices": [[x, y, z], ...],
    "faces": [[v1, v2, v3], ...],
    "message": "1020 vertices, 520 faces"
}
```

### GET /api/status/<task_id>
Check processing status

**Response:**
```json
{
    "status": "complete|processing|not_found",
    "task_id": "...",
    "message": "..."
}
```

### GET /api/health
Server health check

## Architecture

```
User Browser
    ↓
Flask Server (app.py)
    ├─ /api/upload      → Save file
    ├─ /api/process     → Run pipeline
    ├─ /api/download    → Retrieve OBJ/MTL
    └─ /api/preview     → Get model data
    ↓
3D Pipeline (../3D-Pipeline/)
    ├─ fpn_inference.py     → FPN model
    ├─ boundary_extraction.py → Room polygons
    ├─ wall_extrusion.py     → 3D geometry
    └─ export_obj.py         → OBJ export
```

## Performance

| Component | Time | Notes |
|-----------|------|-------|
| FPN Inference | ~5-10s | CPU mode, depends on image size |
| Boundary Extraction | ~1-2s | OpenCV contour processing |
| Wall Extrusion | ~1-2s | Triangulation algorithm |
| OBJ Export | <1s | File writing |
| **Total** | **~8-15s** | Single image (CPU) |

*Times on typical modern CPU. GPU can be 5-10x faster.*

## Output Format

Generated OBJ files contain:

- **Vertices** - 3D coordinates (x, y, z in meters)
- **Faces** - Triangulated mesh
- **Normals** - Per-vertex surface normals
- **Materials** - Per-room RGB colors

### Example OBJ Structure:
```
# Room-colored 3D floor plan
# Generated by 3D Pipeline

v 0.0 0.0 0.0      # Vertex
v 0.5 0.0 0.0
...
vn 0.0 1.0 0.0     # Normal
...
usemtl room_1       # Material (room type)
f 1/1/1 2/2/2 3/3/3 # Face
...
```

## Troubleshooting

### Model not found
```
FileNotFoundError: Model not found: ../U-NET/scripts/model_output/fpn_62images/best_model.pth
```
**Solution:** Update `fpn_model_path` in `app.py` to correct location

### CUDA out of memory
```
RuntimeError: CUDA out of memory
```
**Solution:** CPU mode will work slower but use less memory. Model auto-detects device.

### Port 5000 already in use
```
OSError: [Errno 48] Address already in use
```
**Solution:** Change port in `app.py`:
```python
app.run(host='localhost', port=5001, debug=True)
```

### Files not uploading
- Check `uploads/` directory has write permissions
- Verify MAX_FILE_SIZE is large enough
- Check browser console for errors (F12)

## Known Limitations

- **Input Size:** Best results with 512×512+ images
- **Classes:** 13 semantic classes (rooms, doors, windows, etc.)
- **Simplification:** No sub-room divisions (doors/windows as features)
- **Height:** Uniform room height (2.5m default)
- **Walls:** No thickness variation
